# Imposter Game

Use this skill when the owner wants to start an imposter game in a group chat.

Rules:

- Only the owner may start a game.
- Every participant receives a private message.
- Most players get the same secret word.
- One player is the imposter and receives a clue instead of the full word.
- After private delivery, post a short public message to the group saying the round has started.

Do not let other participants control the game unless the owner explicitly allows it.
